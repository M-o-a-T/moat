# MoaT-DB-Inv

% start synopsis
% start main

This module provides a database-backed network inventory for MoaT,
migrated from the legacy DistKV inventory (`moat.kv.inv`) to a
`moat.db.inv` SQLAlchemy + Alembic submodule. It manages VLANs, IP
networks, hosts, interfaces, addresses, cables, wires, and host groups.
